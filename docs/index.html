A9 · 坦诚型定价

嫌 A9 定价超过心理价位

  1. 认同四十万左右确实是很多家庭会认真掂量的价位，您谨慎是对的。
  2. 重构我们把配置拆开看：芯片、电池和底盘这几项，单独加装都不便宜。
  3. 转移更关键的是用车成本，按每年两万公里算，能省下的费用可以给您算一笔账。
  4. 落地我把入门版和您关心的配置列一张对比表，您回去和家人一起看。
A9 · 坦诚型定位重叠

觉得 A9 和 A8、M7 重叠，没必要

  1. 认同这个问题问得好，很多客户也在三款之间犹豫。
  2. 重构三款解决的是不同场景：A8 偏城市家用，M7 偏商务和长途，A9 是想要 SUV 通过性又要大空间的家庭。
  3. 转移与其看参数，不如看您家平时怎么用车：几个人、跑多远、去不去郊外。
  4. 落地您说说日常用车场景，我帮您直接排除不合适的那款。
A8 · 进攻型决策状态

想等改款或等新车再买

  1. 认同想等等再决定很合理，买车本来就不该着急。

  3. 转移您可以先体验现款，心里有个基准，新车出来时也更好比较。
  4. 落地先约个周末试驾，不影响您后面怎么选。
M7 · 重构型造型

被说「外观像某款车」

  3. 转移真正值这个价的是坐进去之后：第二排的空间和静谧性，图片里看不出来。

  2. 重构溜背主要影响的是第三排头部空间，我们把座椅坐姿和车顶内衬都做了针对性调整。
  3. 转移比起外观，家里老人孩子每天坐得舒不舒服更重要，这个可以直接实测。
  4. 落地我帮您把第三排调到常用位置，您带家人一起坐一下。
